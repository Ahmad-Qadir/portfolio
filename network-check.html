NetworkCheck — Portable Windows Diagnostics

NetworkCheck is a lightweight Windows network troubleshooting tool built with PowerShell for TarinNet testing workflows. It is designed to help on-site teams and less-experienced technicians perform common checks with a simple guided utility. The portable executable runs without installation.

Project Purpose

TarinNet Testing

Created as a practical hobby and testing project for TarinNet network support workflows, helping on-site teams run diagnostics quickly from a Windows workstation.

Portable by Design

The tool is distributed as `NetworkCheck.exe`, allowing on-site staff to run it directly from a USB drive, support folder, or technician workstation without a traditional installer.
